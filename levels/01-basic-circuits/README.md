# Level 1: Basic Circuits

These projects turn isolated components into circuits whose behaviour you can predict.

## Projects

- [LED circuit](../../lessons/01-led-circuit/README.md): current limiting and polarity.
- [Voltage divider](../../lessons/02-voltage-divider/README.md): loading and measured node voltage.
- [Button and LED](../../lessons/03-button-and-led/README.md): switches, pull resistors, and logic states.
- [Transistor switch](../../lessons/04-transistor-switch/README.md): a BJT used as a low-side switch.
- [RC circuit](../../lessons/05-rc-circuit/README.md): charge, discharge, time constants, and thresholds.

## Add these when the core path is comfortable

Build a diode reverse-polarity protector, a MOSFET low-side LED or motor switch, and a simple 555 astable oscillator. Read the relevant datasheet before choosing a transistor, diode, or timer.
