# Level 2: Analog Electronics

Analog projects make the measurements less ideal. Gain, bias, noise, bandwidth, loading, and saturation now matter.

## Project sequence

1. [Light sensor](../../lessons/06-light-sensor/README.md): use an LDR and divider, measure the node over light levels, and explain its non-linearity.
2. [Transistor amplifier](../../lessons/07-transistor-amplifier/README.md): bias a BJT, inject a small signal, and compare input and output amplitude without driving it into clipping.
3. [Op-amp signal conditioner](../../lessons/08-op-amp-conditioner/README.md): build a non-inverting amplifier, check supply limits, and test its response near the rails.
4. [Active filter](../../lessons/09-active-filter/README.md): build a first-order low-pass filter and measure its cutoff response at several frequencies.

Know voltage dividers, RC behaviour, transistor switching, and basic KCL/KVL first. A simulator is useful here, but confirm the real circuit with a meter and, when available, an oscilloscope.
