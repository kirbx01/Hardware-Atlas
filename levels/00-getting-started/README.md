# Level 0: Getting Started

The goal is not to memorize parts. It is to become comfortable identifying connections, powering a circuit safely, and checking what happened with a meter.

## Projects

1. **Breadboard map**: identify connected rows, power rails, the centre gap, and common rail breaks. Test continuity with a meter before applying power.
2. **Multimeter practice**: measure a battery, check continuity with power removed, measure resistance out of circuit, and measure voltage across a powered circuit.
3. **LED circuit**: build the [first LED project](../../lessons/01-led-circuit/README.md). Learn polarity, current limiting, and Ohm's law.
4. **Voltage and current measurements**: extend the [voltage divider](../../lessons/02-voltage-divider/README.md). Measure voltage in parallel. Measure current only by placing the meter in series, never directly across a supply.

## You should be able to

- draw a simple schematic before wiring;
- name the supply, return path, and expected voltage at a test point;
- power down before moving wires;
- explain a measurement instead of only reporting a number.
