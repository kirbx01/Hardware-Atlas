# Level 13: Advanced Hardware

This is the open-ended level: choose a question, build or reproduce a result, measure it honestly, and publish enough detail for someone else to check it.

## Project sequence

1. **Paper replication:** reproduce one measurement or simulation from a hardware paper.
2. **Open hardware investigation:** document a board, instrument, or interface with schematics and measurements.
3. **Research prototype:** define requirements, risks, baselines, and a test plan before building.
4. **Uncertainty report:** separate repeatability, calibration, environmental effects, and model error.
5. **Public artifact:** release source, hardware files, data, limitations, and a reproducible build path.

## Verify

Keep a lab notebook, cite primary sources, record failed attempts, compare against a baseline, and ask for independent review.
