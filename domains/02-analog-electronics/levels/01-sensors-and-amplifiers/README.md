# Analog Electronics Level 01 -- Sensors and Amplifiers

Turning a physical quantity into a measurable voltage, then amplifying a small signal with a biased transistor. The sensor stage is the signal chain's front end; the amplifier is where bias, gain, and clipping start showing who is in charge.

## Why a discrete amplifier before an op-amp

Op-amps package this same idea into a predictable building block. Building one biased transistor stage first is what makes an op-amp's internals feel familiar instead of magical.
