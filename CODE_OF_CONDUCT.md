# Code of Conduct

## Our standard

Hardware Atlas is a learning project for people with different backgrounds and levels of experience. Contributors are expected to be respectful, patient, and specific when discussing hardware, software, documentation, and mistakes.

Examples of welcome behaviour include:

- explaining disagreement with evidence and care;
- asking clarifying questions before assuming intent;
- giving actionable feedback on circuits, code, writing, and safety;
- crediting sources and other contributors;
- making space for beginners to ask basic questions.

Examples of unacceptable behaviour include:

- harassment, discrimination, threats, or personal attacks;
- sexualised language or unwanted attention;
- publishing private information without permission;
- deliberately misleading safety advice;
- disrupting discussions or submitting malicious content.

## Enforcement

Project maintainers may edit, remove, or decline contributions that violate this code. They may also temporarily or permanently restrict participation when necessary to protect the community.

Report a problem by opening a private contact method made available by the repository maintainers, or by opening a GitHub issue if the report does not contain sensitive information. Include links, screenshots, or other context when it is safe to do so.

Reports will be handled as confidentially as practical. Retaliation against someone who raises a good-faith concern is not acceptable.

## Scope

This code applies in project spaces, issue trackers, pull requests, discussions, and other spaces where someone is representing Hardware Atlas.
