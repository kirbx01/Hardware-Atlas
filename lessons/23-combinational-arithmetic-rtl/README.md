# Lesson 23: Combinational Arithmetic RTL

## What you are building

A synthesizable multi-bit ALU in Verilog with simulation waveforms.

## What you will learn

Combinational RTL, width and signedness, carry and overflow, synthesizability, and waveform-based verification.

## Prerequisites

Digital logic and basic Verilog.

## Tools and software

- Verilog
- Icarus Verilog (`iverilog`)
- GTKWave

## Build and test

Define the ALU operations, write a self-checking testbench, simulate corner cases, inspect waveforms, and synthesize the design. Verify carry, borrow, overflow, zero, and invalid-operation behaviour.
