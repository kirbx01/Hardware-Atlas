# Lesson 30: OpenLane Sky130 Flow

## What you are building

An RTL-to-GDSII physical-design run for a small open-source hardware block.

## What you will learn

Constraints, floorplanning, placement, clock and power planning, routing, reports, and reproducible open silicon flows.

## Prerequisites

[Yosys RTL Synthesis](../29-yosys-rtl-synthesis/README.md).

## Tools and software

- OpenLane
- SkyWater SKY130 PDK
- Containerized or documented Linux build environment

## Build and test

Start with a small design and the flow's example configuration. Record tool versions, constraints, warnings, timing, area, and utilization. Treat a completed run as an experiment that needs report review, not as proof of manufacturability.
