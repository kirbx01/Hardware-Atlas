# Lesson 19: KiCad Schematic Capture

## What you are building

A clean microcontroller schematic with decoupling, reset, USB-C programming, and regulated power.

## What you will learn

Schematic hierarchy, net labels, power symbols, decoupling placement, reset pull-ups, USB-C configuration, and ERC checks.

## Prerequisites

[RTOS Sensor Logger](../18-rtos-sensor-logger/README.md) and a working microcontroller project.

## Tools and software

- KiCad
- Microcontroller datasheet and reference design
- USB-C connector, LDO, protection parts, decoupling capacitors, and reset components

## Build and test

Capture the schematic, annotate it, assign footprints, and run electrical-rule checks. Review every power pin and compare the USB-C and regulator sections with manufacturer guidance. Record ERC results and unresolved exceptions.
