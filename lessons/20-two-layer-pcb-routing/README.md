# Lesson 20: Two-Layer PCB Routing

## What you are building

A manufacturable two-layer PCB from the Lesson 19 schematic.

## What you will learn

Footprints, design rules, trace-width limits, ground pours, return paths, placement, Gerbers, and revision control.

## Prerequisites

[KiCad Schematic Capture](../19-kicad-schematic-capture/README.md).

## Tools and software

- KiCad PCB Editor
- Fabricator design rules
- Datasheets and footprint drawings

## Build and test

Place connectors and power parts first, route critical signals, add a ground pour, and run DRC. Check current capacity, clearances, mounting dimensions, and generated Gerbers in a viewer before ordering.
