# Lesson 26: RISC-V Single-Cycle Datapath

## What you are building

A small RV32I single-cycle processor core with instruction memory and a traced register file.

## What you will learn

Instruction fetch and decode, register files, ALU control, immediate generation, branches, loads, stores, and architectural tests.

## Prerequisites

[FPGA and RTL](../../levels/08-fpga-rtl/README.md), [cocotb Python Testbench](../25-cocotb-python-testbench/README.md), and basic assembly.

## Tools and software

- Verilog simulator and waveform viewer
- RISC-V assembler or hand-encoded test programs
- Reference model or instruction-level test harness

## Build and test

Implement a limited, documented RV32I subset first. Load short programs into instruction memory, trace register and memory state, and compare results against a reference model.
