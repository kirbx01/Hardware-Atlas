# Projects

Projects are the core of Hardware Atlas. The first detailed projects are currently kept in `lessons/` because they form one continuous beginner path.

When this directory grows, each project should use a short, stable slug and include:

- `README.md` with the build, learning goal, prerequisites, components, tools, software, difficulty, measurements, resources, common mistakes, and next project;
- optional `metadata.yaml` containing only maintainers' structured fields;
- a link from the relevant level page;
- a measured result or test, not only a claim that the circuit worked.

A good project has one main idea. It can be extended later, but the first version should be buildable with the listed parts and should not require an expensive lab.
