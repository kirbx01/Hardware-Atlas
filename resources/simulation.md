# Simulate Before Building

Simulation is useful for checking an idea, finding a wrong polarity, estimating a time constant, and exploring values before buying parts. It does not prove that a breadboard layout, power supply, thermal design, or physical component will work.

- [Wokwi](https://wokwi.com/): browser simulation for Arduino, ESP32, STM32, and Raspberry Pi Pico projects, including firmware experiments.
- [Tinkercad Circuits](https://www.tinkercad.com/circuits): approachable visual circuits and Arduino simulation for first projects.
- [Falstad Circuit Simulator](https://www.falstad.com/circuit/): animated circuit-level intuition for RC, RLC, diode, transistor, and other analogue circuits.
- [EasyEDA](https://easyeda.com/): schematic and PCB design environment; use it after the circuit behaviour is understood, not as a replacement for reading datasheets.

For a complicated circuit, simulate the smallest uncertain block, write down expected measurements, then build and compare. Investigate any large difference before adding more parts.
